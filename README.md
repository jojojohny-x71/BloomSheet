# Bloom sheet

A motion prototype of a **bloom sheet**: a full-screen takeover that blooms up from the bottom of the screen in place of a bottom sheet. The screen behind blurs, dims and recedes, a lime-green glow rises from the bottom edge, and the content fades in one item at a time.

The example is a trading app telling the user they're over their lot cap.

## Try it

Open `index.html` in a browser.

- Tap the pill or the mascot to open the bloom sheet.
- Tap **Ignore**, press **Esc**, or tap the dimmed area to close it.

A single HTML file with no dependencies or build step.
